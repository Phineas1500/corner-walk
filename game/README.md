# Corner Walk

The Mac receiver generates a Game Boy Color checkpoint game from each finished
walk. Longer walks become up to three levels. Collect every stamp in a level to
open its gate. The dashed lane is a shortcut patrolled by a drone. If it catches
you, you return to the level entrance with your stamps.

Use the D-pad to move. Press **A** on a marked tile to read the recorded
observation, chat or place name. Press **B** to see your stamp count and number
of times caught. The last gate awards a clean run if you avoided the drone.

Indoor levels follow the order of stops. Outdoor levels follow successive legs
of the GPS route and can mirror to reflect the direction of travel.

The starter room, character, fixed-width font and dialogue UI come from the
starter example of the ModRetro Chromatic plugin for Codex. See
[third-party notices](../THIRD_PARTY_NOTICES.md) for the source and license.
The font covers printable ASCII; lowercase has a small-caps appearance and
other characters use a question-mark fallback.

The receiver leaves an editable GB Studio project beside each generated ROM.
Native project-format metadata retains its upstream license notice in `LICENSE`.
